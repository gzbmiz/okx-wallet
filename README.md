## OKX Wallet 是什麼？

OKX Wallet 是一款**非託管錢包**。這代表錢包的私鑰或助記詞由使用者自行保管，平台不會像交易所帳戶一樣代替使用者管理資產。

這種設計帶來比較大的自主權，但責任也一起轉到使用者身上：

- 忘記交易所登入密碼，通常可以透過帳戶流程找回。
- 忘記 Web3 錢包密碼，可能需要透過助記詞或私鑰重新導入。
- 助記詞遺失，通常無法由平台代為找回。
- 助記詞被他人取得，對方可能直接控制錢包資產。

OKX 官方說明指出，Web3 錢包不會儲存使用者的密碼、助記詞或私鑰，也無法替使用者找回遺失的助記詞。這正是非託管錢包和中心化交易所帳戶之間最重要的差異。

如果你只想買入比特幣或穩定幣，交易所帳戶可能已經足夠。如果你需要連接 DeFi、NFT 市場、鏈上遊戲或其他 DApp，就會用到 OKX Wallet。

常見流程是：

最安全的做法是先用小額資產測試，確認地址和網路都正確後，再處理較大金額。

## 如何從 OKX Wallet 收款？

收款時最重要的不是複製地址本身，而是確認**幣種和網路完全一致**。

以 App 為例：

1. 開啟 OKX Wallet。
2. 點選收款。
3. 選擇要接收的幣種。
4. 選擇正確網路。
5. 複製錢包地址或顯示 QR Code。
6. 將地址提供給轉出方。
7. 等待區塊鏈確認。

例如，你要接收 USDT，可能會看到 Ethereum、Tron、BNB Smart Chain、Arbitrum 等不同網路。對方從哪一條網路轉出，你就必須提供同一條網路的收款地址。

常見錯誤包括：

- 對方使用 TRON 網路，你卻選擇 Ethereum 網路。
- 轉入需要 Memo 或 Tag 的資產時沒有一併提供。
- 只看幣種名稱，沒有確認網路名稱。
- 從交易所提幣時選錯鏈。
- 複製了其他帳戶或其他錢包的地址。

如果是第一次使用，建議先用小額測試。區塊鏈交易一旦確認，通常不能像銀行轉帳那樣直接撤回。

## 如何從 OKX Wallet 發送資產？

發送資產前，先準備三項資料：

- 收款地址
- 幣種名稱
- 網路名稱

操作步驟通常如下：

1. 進入錢包資產頁面。
2. 選擇要發送的代幣。
3. 點選發送。
4. 貼上收款地址。
5. 確認網路和代幣。
6. 輸入轉帳數量。
7. 查看預估 Gas 和實際到帳數量。
8. 確認地址前幾碼和後幾碼。
9. 輸入錢包密碼並簽署交易。
10. 等待鏈上確認。

不要只依賴複製貼上。某些惡意軟體會替換剪貼簿中的加密貨幣地址，因此貼上後一定要人工核對開頭和結尾。

OKX 官方說明指出，網路費會根據區塊鏈狀態即時變動，並且通常按照交易次數收取，而不是按照轉帳金額比例收取。若交易失敗，已經支付的網路費可能不會退回。

## 如何在 OKX Wallet 內兌換代幣？

OKX Wallet 內建 DEX 和跨鏈兌換相關功能。實際可用幣種、路由、報價和費用會依照網路及市場狀況變化。

一般兌換流程如下：

1. 開啟錢包內的兌換或 Swap 功能。
2. 選擇要支付的代幣。
3. 選擇要換取的代幣。
4. 確認使用的網路。
5. 輸入兌換數量。
6. 查看預估到帳數量、滑點和網路費。
7. 如系統要求，先完成代幣授權。
8. 確認報價後簽署交易。
9. 等待鏈上確認。

要留意三種不同成本：

- **Gas Fee**：支付給區塊鏈網路。
- **滑點**：實際成交價格和預估價格之間的差異。
- **服務費或聚合路由成本**：視功能和交易路由而定。

「兌換成功」不代表一定拿到原本預估的完整數量。市場流動性不足、交易量較大或滑點設定過高，都可能影響實際成交結果。

如果代幣名稱相同，還要確認合約地址。鏈上可能存在同名代幣，名稱和圖示本身不能作為唯一判斷依據。

## 如何用 OKX Wallet 連接 DApp？

連接 DApp 時，錢包只是負責提供地址和簽署交易，並不代表 OKX 背書該網站或智能合約。

常見連接步驟如下：

1. 使用瀏覽器開啟 DApp。
2. 點選 Connect Wallet 或連接錢包。
3. 選擇 OKX Wallet。
4. 確認網站網域是否正確。
5. 在錢包視窗確認連接請求。
6. 確認目前使用的地址和網路。
7. 只在理解請求內容後簽署。

連接錢包和授權代幣是兩件不同的事：

- 連接錢包：DApp 可以看到你的公開地址和鏈上公開資料。
- 代幣授權：你允許某個智能合約代表你使用特定代幣。
- 簽署交易：你批准一筆可能會改變資產狀態的鏈上操作。

看到「Approve」「Permit」「Set approval」等字樣時，不要當成普通登入按鈕。先確認授權對象、代幣種類、額度以及是否允許無限額使用。

## OKX Wallet 安全設定清單

建立錢包後，建議立刻完成以下設定：

- 將助記詞離線備份至少一份。
- 不要把助記詞輸入任何客服聊天視窗。
- 不要將助記詞提供給所謂的空投、驗證或解鎖頁面。
- 為錢包設定獨立且不重複的密碼。
- 開啟手機和瀏覽器的裝置鎖定。
- 大額資產考慮使用硬體錢包。
- 定期檢查代幣授權。
- 交易前確認網站網域、鏈、地址和合約。
- 先以小額測試新地址或新 DApp。
- 不要相信「客服要求你轉帳驗證資產」這類訊息。

OKX 官方對 Web3 錢包的說明也將助記詞保管、密碼安全和防範釣魚攻擊列為使用者的主要責任。

> 任何人只要要求你提供助記詞、私鑰或錢包密碼，都不應該照做。真正的客服不需要這些資訊來「解凍」或「驗證」你的資產。

## 常見問題

### OKX Wallet 需要身份驗證嗎？

建立 Web3 錢包本身，和開立交易所帳戶是不同流程。OKX 官方 FAQ 表示，Web3 錢包可直接建立或導入，不一定需要交易所帳戶的身份驗證。但如果你要使用交易所買賣、法幣入金或其他受監管服務，則可能需要按照所在地區和產品要求完成驗證。

### OKX Wallet 是冷錢包嗎？

OKX Wallet 是軟體錢包，主要運作在手機、瀏覽器或 Web 端。不能因為資產由使用者自行掌控，就直接把它和離線硬體冷錢包混為一談。安全性除了取決於錢包本身，也取決於裝置、助記詞備份方式和使用者是否誤簽惡意交易。

### 為什麼有地址但收不到資產？

先檢查以下內容：

1. 交易是否已在區塊鏈上確認。
2. 發送方是否選擇正確網路。
3. 你查看的是否是相同地址。
4. 代幣是否需要 Memo 或 Tag。
5. OKX Wallet 是否已顯示該代幣。
6. 是否使用了正確的區塊瀏覽器查看交易。

有些代幣已經到達地址，但錢包介面尚未自動顯示。這種情況不代表資產一定遺失，可以先透過交易雜湊和區塊瀏覽器確認鏈上狀態。

### 轉帳時一定要支付 Gas 嗎？

大多數鏈上轉帳都需要支付網路費，費用通常以該網路的原生代幣支付，例如 Ethereum 網路使用 ETH、TRON 網路使用 TRX，X Layer 則可能使用 OKB。實際金額會依網路和交易類型變化，應以錢包確認頁面顯示為準。

### 邀請碼 CASH20 是 OKX Wallet 的錢包密碼嗎？

不是。`CASH20` 是邀請碼，不是錢包密碼、助記詞或私鑰。

如果註冊頁面要求輸入邀請碼，可以按照頁面提示填寫；如果頁面沒有相關欄位，不要把邀請碼當成錢包密碼使用。實際優惠是否適用，仍以註冊頁面和當時的官方規則為準。
